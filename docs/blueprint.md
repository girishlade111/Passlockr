# **App Name**: Passlockr

## Core Features:

- Password Input: Password Input: Provides a text input field where users can type or paste their password.
- Strength Indicator: Visual Strength Indicator: Displays a real-time strength bar that changes color and length based on the password's strength.
- Textual Feedback: Textual Feedback: Offers immediate feedback (e.g., Weak, Medium, Strong) corresponding to the password's strength.
- Improvement Tips: Complexity Suggestions Tool: Uses an AI model to analyze the password and provide actionable suggestions to improve its complexity.
- Generate Password: Password Generation: Functionality to generate strong, random passwords based on user-defined criteria (length, characters).

## Style Guidelines:

- Background color: Dark gray (#222222) to provide a sleek dark mode experience.
- Primary color: Electric blue (#7DF9FF) for main elements and interactive components, providing contrast and visual interest on the dark background.
- Accent color: Lavender (#E6E6FA), complementing the electric blue and adding a softer highlight.
- Strength Indicator Gradient: Visual strength indicator utilizes a gradient from intense red (#FF4136) for weak passwords to vivid green (#2ECC40) for strong ones.
- Body and headline font: 'Inter', a grotesque-style sans-serif, to create a modern, neutral and machined style.
- Minimalist Icons: Uses simple, geometric icons to represent password criteria (length, uppercase, symbols).
- Smooth Transitions: Provides fluid transitions for strength indicator updates and feedback messages.
